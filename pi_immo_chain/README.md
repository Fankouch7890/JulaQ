# Pi ImmoChain Tunisia 🇹🇳 (منصة عقارات شبكة باي في تونس)

**Pi ImmoChain Tunisia** هي منصة إلكترونية لامركزية مخصصة لسوق العقارات في تونس (شراء، بيع، وكراء العقارات، الشقق، الفيلات والأراضي) باستخدام عملة **Pi Network** وعبر متصفح **Pi Browser**.

---

## 🌟 المميزات (Features)

1. **التكامل المباشر مع Pi SDK 2.0**:
   - تسجيل الدخول والتوثيق بحساب Pi (`Pi.authenticate`).
   - إجراء المعاملات وتأكيد الدفع والتسقيع المالي (`Pi.createPayment`).
2. **سوق عقاري تونسي شامل**:
   - تغطية أهم الولايات والمناطق السياحية والسكنية: تونس العاصمة، سوسة والقنطاوي، الحمامات، جربة، صفاقس، المنستير، وبنزرت.
   - دعم تصنيفات متعددة: شقق (S+1, S+2, S+3)، فيلات فاخرة، أراضي للبناء، ومحلات تجارية.
3. **تصفية وبحث متقدم**:
   - البحث حسب الولاية، نوع العقد (بيع / كراء)، ونوع العقار.
4. **عرض التفاصيل وإضافة عقار جديد**:
   - إمكانية إضافة ملاك العقارات لعقاراتهم مباشرة من داخل متصفح Pi Browser.

## 🚀 كيفية التشغيل والاستضافة (Deployment Guide)

### 1. الاستضافة المجانية على GitHub Pages
1. انشر ملفات المجلد `pi_immo_chain` على مستودع GitHub الخاص بك.
2. فعّل خدمة **GitHub Pages** من إعدادات المستودع (Settings -> Pages -> Branch: main).
3. ستحصل على رابط HTTPS مباشر للموقع (مثال: `https://username.github.io/pi_immo_chain/`).

### 2. التسجيل في Pi Developer Portal
1. افتح تطبيق **Pi Browser** من هاتفك المحمول.
2. ادخل إلى الرابط `develop.pi`.
3. اضغط على **"New App"** وأدخل البيانات التالية:
   - **App Name**: Pi ImmoChain Tunisia
   - **App URL**: رابط GitHub Pages الخاص بك (`https://username.github.io/...`)
   - **Development URL**: نفس الرابط مع تفعيل وضع الاختبار (Sandbox Mode).
4. انسخ معرف التطبيق (App ID) وأكّد عملية الربط.
